---
name: job-application-forms
description: Efficiently complete varied online job-application forms using a local profile, site-specific field maps, and review checkpoints.
---

Use this skill for browser-based applications across ATS platforms such as Ashby, Greenhouse, Lever, and Workday.

1. Identify the ATS and capture visible field labels once.
2. Load reusable answers and map by label, not DOM position.
3. Fill only fields supported by stored facts; never infer sensitive, legal, demographic, or employment-history answers.
4. Keep optional self-identification fields declined unless the profile explicitly specifies a response.
5. Verify uploads, required fields, and validation errors.
6. Stop at final submit and present a concise review summary; submission requires final user confirmation.
